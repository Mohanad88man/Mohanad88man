# مواصفة WhatsApp Wallpaper Pro

## الهدف
تطبيق أندرويد محلي بواجهة عربية RTL يحوّل الصور إلى خلفيات محادثة مع احتواء كامل للصورة وخلفية ذكية، دون تسجيل دخول أو رفع خارجي.

## النطاق
اختيار صورة عبر Android Photo Picker، تحليل الأبعاد، معاينة داخل نموذج محادثة، Fit/Contain، خلفية ضبابية أو لون ذكي أو لون مخصص، تكبير/تحريك، تصدير PNG/JPG/WebP إلى MediaStore، ومشاركة الملف.

## التقنية
Kotlin، Jetpack Compose Material 3، MVVM، Android 15 target، minSdk 26، معالجة Bitmap داخل الجهاز، MediaStore.

## معايير القبول
- لا تطلب صلاحية قراءة التخزين أو جهات الاتصال أو الرسائل.
- الصورة الأصلية كاملة في وضع الاحتواء، مع منع التشويه والقص التلقائي.
- يدعم مقاسات 1080×1920، 1920×1080، 1080×1080 ومقاسًا مخصصًا.
- التصدير يحفظ في Pictures/WhatsApp Wallpaper Pro ويتيح المشاركة.
- فشل الصورة التالفة أو نقص المساحة يعرض رسالة مفهومة.
- الواجهة تعمل في الوضع الفاتح والداكن وتدعم RTL.

## حدود النسخة الأولى
Super Resolution الحقيقي غير مضمن؛ خيار التحسين يستخدم ترشيح Bitmap عالي الجودة لتجنب تضخيم غير موثوق. الخلفية الضبابية تقريبية محليًا عبر نسخة مصغرة، ويمكن استبدالها لاحقًا بخوارزمية GPU/ML.
