# WhatsApp Wallpaper Pro

تطبيق Android محلي لمعالجة الصور كخلفيات محادثة مع الحفاظ على الصورة كاملة.

## البناء

يتطلب Android Studio أو JDK 17 وAndroid SDK Platform 35. افتح المشروع ثم شغّل:

```bash
./gradlew assembleDebug
```

الناتج المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.

## الخصوصية
يستخدم التطبيق Photo Picker ولا يطلب صلاحيات تخزين واسعة أو جهات اتصال أو رسائل. تتم المعالجة والتصدير على الجهاز فقط.

## الخوارزمية
تُفك الصورة بأبعاد آمنة، تُدار حسب EXIF، ثم تُرسم داخل مساحة الإخراج بنسبة احتواء. الفراغات تُملأ بخلفية ضبابية مستخرجة من الصورة أو لون ذكي متوسط، دون قص أو تمديد للصورة الأصلية.
